# vehicle

Car, police, and boat models. `car_*.glb` come from `assets-src/blender/cars.py` (see `assets-src/blender/README.md` for nodes, sizes, and integration); `sports_car.glb` and `police.glb` are the generated sports and police bodies the game still loads (they looked better in the game than `car_sports` and `car_police`, which are kept here but not shipped); `boat.glb` is the boat.
