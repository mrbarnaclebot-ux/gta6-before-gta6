# audio

Made by `scripts/audio.mjs` from the owner's Epidemic Sound downloads; do not edit by hand. Credits and licence: `../CREDITS.md`.

- `ui-*` menu and HUD sounds; `step-<surface>-N` single footsteps; other short names are one-shots, `-N` marks variants
- `engine-*`, `outboard`, `wake`, `swim`, `skid`, `siren`, `amb-*` are seamless loops with 0.1 s of wrap-around audio past each end (the game loops between those points)
- `music-*` and `radio-*` stream through an audio element
