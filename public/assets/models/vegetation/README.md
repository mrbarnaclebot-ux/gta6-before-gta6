# vegetation

Plant models. Sources and licences are in `../../CREDITS.md`.

- `palm.glb`, `palm_far.glb` the coconut palm, near and far versions
- `ph_fern_02.glb` four scanned ferns for the city's planters
- `fir_a.glb`, `fir_b.glb` firs for the forest and hills
- `jacaranda.glb`, `island_tree_01.glb` broadleaf trees for the woods and copses
- `island_tree_02.glb`, `tree_small_02.glb` garden trees
- `bushes.glb` four shrubs (nodes `bush_a` .. `bush_d`): undergrowth, gardens, hedges
- `rocks_moss_01.glb`, `rocks_moss_02.glb` mossy rocks, one node per rock

Each tree file holds three groups: `bark` (near trunk), `lite` (far trunk), and `foliage` (leaf cards). The trunk base is at the origin.
