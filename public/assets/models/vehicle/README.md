# vehicle

Meshopt copies of `assets-src/models/vehicle` (built by `scripts/compress-assets.mjs`). `car_*.glb` are the Blender library cars (see `assets-src/blender/README.md`); `sports_car.glb` and `police.glb` are the generated sports and police bodies the game still loads (they looked better in the game than the Blender `car_sports` and `car_police`, which `compress-assets.mjs` leaves out); `boat.glb` is the boat.
